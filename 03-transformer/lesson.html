本课的核心问题是：一堆孤立的向量，怎么变成"理解了上下文"的表示？答案就是 Transformer 中的 Self-Attention（自注意力）机制。

1 核心问题：为什么 Embedding 不够？

经过 Embedding 查找后，每个 token 都有了一个向量。但这些向量有一个致命缺陷：它们之间是完全孤立的。

举个例子，考虑这两句话：

# 同一个字"苹果"，但语义完全不同： "我买了一个苹果吃" → 水果 🍎 "我买了一个苹果手机" → 品牌 📱 # Embedding 查找表只能给"苹果"一个固定向量 # 它不知道旁边是"吃"还是"手机"

问题很明显：一个词的真正含义取决于它周围的上下文。光靠查表得到的固定向量是不够的。模型需要一种方法，让每个 token 能"看到"周围的 token，然后根据上下文动态调整自己的表示。

一个类比：课堂讨论

想象一个教室里有 10 个学生（= 10 个 token），每人手里有一张卡片写着自己的初始观点（= Embedding 向量）。

如果每个人只看自己的卡片就直接作答——结果肯定很差。

但如果允许他们互相讨论呢？每个人可以看看其他人的卡片，根据相关性决定要从谁那里吸收多少信息，然后更新自己的答案。

讨论结束后，每个人的最终观点（= 更新后的向量）已经融合了整个上下文的信息。

Self-Attention 就是这个"讨论"过程的数学实现。

2 Self-Attention：让 Token 互相"对话"

Self-Attention 的核心思想用一句话概括就是：每个 token 给序列中的其他所有 token 打一个"相关性分数"，然后按照分数加权求和，得到融合了上下文信息的新向量。

让我们一步步拆解这个过程。假设输入是 "猫 坐在 垫子 上"（4 个 token）：

Step 1：生成 Q、K、V 三个向量

每个 token 的 Embedding 向量通过三个不同的线性变换，生成三个新向量：

# 对于每个 token，生成三个"角色"： Query (Q) = "我在找什么信息？" # 相当于"提问" Key (K) = "我能提供什么信息？" # 相当于"标签/关键词" Value (V) = "我实际包含的信息" # 相当于"内容" # 计算方式：三个权重矩阵 W_Q, W_K, W_V Q = embedding × W_Q # (d_model → d_k) K = embedding × W_K # (d_model → d_k) V = embedding × W_V # (d_model → d_v)
直觉类比：想象你在图书馆找书。
你脑中的问题是 Query（"我想找关于猫的书"）。
每本书的封面标题是 Key（"猫的生活习性""狗的训练方法""量子力学导论"……）。
书的内容是 Value。

你拿自己的 Query 和每本书的 Key 做比较（点积），得到相关性分数。分数高的书你多看，分数低的略过。最终你获得的知识 = Value 的加权求和。

Step 2：计算注意力分数

用每个 token 的 Query 去和所有 token 的 Key 做点积。点积越大 = 越相关。

# "猫"的 Query 和所有 token 的 Key 做点积： score(猫, 猫) = Q_猫 · K_猫 = 3.2 # 自己和自己比较相关 score(猫, 坐在) = Q_猫 · K_坐在 = 1.5 # 动作，有点相关 score(猫, 垫子) = Q_猫 · K_垫子 = 2.8 # "猫"和"垫子"高度相关！ score(猫, 上) = Q_猫 · K_上 = 0.3 # 虚词，不太相关 # 除以 √d_k 做缩放（防止点积值过大导致梯度消失） scaled_scores = scores / √d_k

Step 3：Softmax 变成权重

对分数做 Softmax（和上节课学的完全一样），让它们变成 0~1 之间的权重，总和为 1：

weights = softmax([3.2, 1.5, 2.8, 0.3]) = [0.38, 0.07, 0.25, 0.02] # 猫↑ 坐在↑ 垫子↑ 上↑ # 注意：真实模型这里会 normalize 到更合理的分布

Step 4：加权求和得到输出

用这些权重对所有 token 的 Value 向量做加权求和，得到"猫"这个位置融合了上下文后的新表示：

output_猫 = 0.38 × V_猫 + 0.07 × V_坐在 + 0.25 × V_垫子 + 0.02 × V_上 # 现在"猫"的向量已经吸收了来自"垫子"的信息！ # 模型知道了"这是一只坐在垫子上的猫"而不仅仅是一个孤立的"猫"字

用一个公式总结：

Attention(Q, K, V) = softmax(Q × KT / √dk) × V
💡

核心直觉：Self-Attention 本质就是一个"智能加权平均"。普通的平均会平等对待所有 token，而 Self-Attention 会根据相关性动态分配权重——相关的 token 权重大，不相关的接近零。这让每个位置的向量都能"看到全局"，但只从真正相关的位置吸收信息。

从这些热力图中可以观察到几个有趣的模式：

1. 代词解析："它"会把大部分注意力给前面的名词（"猫"），这说明模型在学习指代关系。

4 因果遮罩：不能"偷看未来"

你可能注意到了一个问题：在生成文本时，模型是逐字生成的。当它在预测第 3 个 token 时，第 4、5、6……个 token 还不存在。如果 Self-Attention 允许"看到后面的 token"，那在训练时模型就能"偷看答案"了——这完全违背了 Next-Token Prediction 的训练目标。

解决方案是 因果遮罩（Causal Mask）：在计算注意力分数时，把当前位置之后的所有位置强制设为负无穷（-∞），Softmax 之后这些位置的权重就变成了 0。

# 因果遮罩的效果（✓ = 可以看到，✗ = 被遮住） # 看→ token1 token2 token3 token4 # token1 ✓ ✗ ✗ ✗ ← 只能看自己 # token2 ✓ ✓ ✗ ✗ ← 能看到前 2 个 # token3 ✓ ✓ ✓ ✗ ← 能看到前 3 个 # token4 ✓ ✓ ✓ ✓ ← 能看到所有（它是最后一个） # 实现方式：在 softmax 之前，给上三角位置加 -∞ scores[i][j] = -∞ if j > i # j 在 i 后面 → 遮住
🎭

一个重要区别：GPT 这类"生成式"模型用因果遮罩（只能看前面），叫做 Decoder-only 架构。而 BERT 这类"理解式"模型不用遮罩（每个 token 都能看到全文），叫做 Encoder 架构。当前主流大模型（GPT-4、Claude、LLaMA、DeepSeek）全部是 Decoder-only——因为生成能力是最通用的。

5 Multi-Head Attention：从多个角度"看"

一组 Q/K/V 只能学习一种"注意力模式"。但语言中的关系是多维度的——一个词可能和另一个词在语法上相关，同时和第三个词在语义上相关。一个"注意力头"很难同时关注多种关系。

解决方案：多头注意力（Multi-Head Attention）——并行运行多个独立的 Attention 计算，每个"头"可以学习关注不同类型的关系。最后把所有头的输出拼接起来。

为什么用多个小头而不是一个大头？假设总维度是 768。一个头用 768 维做注意力，只能学一种关注模式。12 个 64 维的头，能同时学 12 种不同的模式。这就像 12 个不同的"专家"各自从不同角度分析同一句话，最后综合所有人的意见——比一个"全能专家"效果好得多。而且计算量是一样的！

6 位置编码：教模型理解顺序

Self-Attention 有一个隐藏的问题：它本身不关心 token 的顺序。

你把 "猫吃鱼" 和 "鱼吃猫" 的 token 打乱顺序喂给 Self-Attention，只要 token 集合相同，计算结果可能完全一样——因为注意力分数只看向量内容，不看位置。但这两句话的意思完全相反！

解决方法是 位置编码（Positional Encoding）：给每个位置一个独特的"身份标识"向量，加到 Embedding 向量上，让模型知道"这个 token 在第几个位置"。

# 位置编码的加入方式（注意是"加"不是"拼接"） final_input[i] = embedding[token_i] + position_encoding[i] # 位置 0: embedding("猫") + pos_vec_0 # 位置 1: embedding("吃") + pos_vec_1 # 位置 2: embedding("鱼") + pos_vec_2 # 现在模型能区分"猫在第1位"和"猫在第3位"了

位置编码有两种常见实现方式：

① 正弦位置编码（Sinusoidal）——原始 Transformer 论文使用。用不同频率的正弦/余弦函数生成每个位置的向量。优点是可以泛化到训练时没见过的长度，缺点是固定不可学习。

② 旋转位置编码（RoPE）——当前主流方案（LLaMA、GPT-4、DeepSeek 都在用）。核心思想是把位置信息编码为向量的旋转角度。在计算 Q·K 点积时，两个位置之间的"距离"自然体现为旋转角之差。优雅、高效、支持长序列外推。

🔑

位置编码的直觉：你可以把它类比为音乐的节拍标记。一首歌的歌词如果打乱了顺序就没有意义——你需要知道每个音符在第几拍。位置编码就是给每个 token 打上"节拍号"，让模型知道"这个词是出现在句首、句中还是句尾"以及"这两个词之间隔了多远"。

7 完整的 Transformer Block

Self-Attention 只是 Transformer 的核心组件之一。一个完整的 Transformer Block（块）还包含 Feed-Forward Network（前馈网络）、Layer Normalization（层归一化）和 Residual Connection（残差连接）。让我们一一了解：

输入向量（来自上一层）
↓
Layer Norm
↓
Multi-Head Self-Attention ← 残差连接 →
+
Layer Norm
↓
Feed-Forward Network (MLP) ← 残差连接 →
+
↓
输出向量（送入下一层）

逐个解释这些组件：

🔹 Feed-Forward Network（FFN / MLP）

Self-Attention 负责"token 之间的信息交流"，而 FFN 负责"对每个 token 各自做深层处理"。它是一个简单的两层全连接网络，中间维度通常是 Embedding 维度的 4 倍：

FFN(x) = max(0, x × W₁ + b₁) × W₂ + b₂ # 维度变化：d_model → 4×d_model → d_model # max(0, ...) 就是 ReLU 激活函数（或现代变体如 SwiGLU） # 研究认为 FFN 充当了模型的"记忆库"，存储事实性知识

🔹 Residual Connection（残差连接）

把输入直接加到输出上：output = layer(x) + x。好处：① 让梯度能畅通地反向传播（解决深层网络训练困难的问题）；② 让每一层只需学习"增量改进"，而不是从零重建整个表示。

🔹 Layer Normalization

将向量的数值标准化（均值=0，方差=1），防止数值在层与层之间越来越大或越来越小。就像定期"校准仪表"。

📚

FFN 是"记忆"，Attention 是"推理"：研究者发现了一个有趣的分工——FFN 层倾向于存储事实性知识（如"巴黎是法国首都"），而 Attention 层负责在上下文中做推理和信息整合（如"他说的那个城市"指的是哪里）。这两者交替出现，让模型既有"知识"又有"思考能力"。

8 层层堆叠：从浅到深

一个 Transformer Block 只是一层。真实的大模型会把这个 Block 重复堆叠几十到上百次：

# 各模型的层数对比： GPT-2 Small: 12 层 (117M 参数) GPT-2 XL: 48 层 (1.5B 参数) GPT-3: 96 层 (175B 参数) LLaMA-2 70B: 80 层 (70B 参数) DeepSeek-V3: 61 层 (671B 参数, MoE)

每一层的 Attention 都在做"信息交流"，但关注的东西越来越抽象：

浅层（1-10 层）：学习局部的词法和语法模式。
比如："un" + "happy" → 否定含义；主语后面跟动词

中层（10-50 层）：学习句法结构和语义关系。
比如：指代消解（"它"指谁）；从句嵌套

深层（50+ 层）：学习高级推理和世界知识。
比如：因果推断；类比推理；常识判断

这和人类视觉系统的分层很像：视网膜检测边缘 → V1 区识别简单形状 → V2/V4 识别纹理和物体 → IT 区识别面孔和场景。信息每经过一层，抽象程度就提高一级。

🏗️

完整的前向传播路径：
原始文本 → Tokenize → Token IDs → Embedding + Position Encoding → [Transformer Block × N 层] → 最后一层的输出向量 → Linear + Softmax → 词表上的概率分布 → 选出"下一个 token"

从第一个 token 进入到最后输出概率，整个过程只涉及矩阵乘法、加法和少量非线性操作。这就是为什么 GPU 的大规模并行计算能力对大模型如此重要。

9 检验你的理解

回答下面的问题来巩固对 Transformer 的理解。

Q1: Self-Attention 中的 Q、K、V 分别代表什么直觉？

✅ 正确！Query 像"提问"，Key 像"标签"，Value 像"内容"。用 Q 和 K 的相似度算出权重，然后按权重取 V 的加权和。就像用问题去匹配书的标题，然后按匹配度取书的内容。
❌ 想想图书馆的类比：你有一个问题（Query），书架上的书有标题（Key）和内容（Value）。你根据问题和标题的匹配度，决定从每本书中取多少内容。

Q2: 为什么 GPT 模型需要因果遮罩（Causal Mask）？

✅ 正确！在生成时，模型逐字生成，未来的 token 还不存在。训练时用因果遮罩模拟这种"只能看前面"的约束，确保训练和推理的行为一致。如果允许看到未来，模型就不需要"预测"了——直接抄答案就行。
❌ 遮罩和计算量关系不大（它实际上不减少计算）。核心原因是：生成文本时模型看不到未来，训练时也不应该看到。

Q3: Multi-Head Attention 的"多头"有什么好处？

✅ 正确！一个头只能学一种关注模式，多个头可以并行学习多种关系——有的头关注语法、有的关注指代、有的关注位置距离。把它们的信息合并，模型就能同时捕捉语言中的多种结构。
❌ 多头的总计算量和单头基本相同（只是把维度拆分了）。多头的核心优势是"多角度分析"——每个头可以学习不同的关注模式。

Q4: Transformer 中残差连接（Residual Connection）的主要作用是？

✅ 正确！没有残差连接，梯度在 96 层中反向传播时会指数级衰减（梯度消失），模型根本无法训练。残差连接提供了一条"高速公路"让梯度直通底层，同时让每层只需学习"增量改进"。这是训练深层网络的关键技巧。
❌ 残差连接不影响参数量或序列长度。它的核心作用是解决深层网络的梯度传播问题——把 output = f(x) 改为 output = f(x) + x，让梯度能直接传到底层。

10 编程练习：手写 Self-Attention

本课的编程练习会让你从零实现 Self-Attention 的核心计算——这是整个 Transformer 中最关键、也是最优雅的部分。实现之后，你会发现所谓的"注意力机制"在代码上并不复杂——它的深刻之处在于设计思想而非代码量。

🛠️ 你的任务：手写 Self-Attention

在配套的 exercise.py 中，按顺序完成 5 个任务：

任务 1：compute_attention_scores() — 计算 Q 和 K 的点积注意力分数
对于每对 (query_i, key_j)，用点积衡量它们的相关性。然后除以 √d_k 做缩放。

任务 2：apply_causal_mask() — 应用因果遮罩
把未来位置（j > i）的分数设为负无穷，让模型无法"偷看未来"。

任务 3：compute_attention_weights() — 对分数做 Softmax 得到权重
每一行做一次 Softmax，让权重变成概率分布（0~1，每行之和=1）。

任务 4：compute_attention_output() — 用权重对 V 做加权求和
每个位置的输出 = Σ(权重_j × V_j)。这是"信息融合"的关键步骤。

任务 5：self_attention() — 串联所有步骤，完成完整的 Self-Attention
生成 Q/K/V → 计算分数 → 遮罩 → Softmax → 加权求和。一次完整的"token 对话"过程。
